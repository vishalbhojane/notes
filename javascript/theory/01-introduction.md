## What is JavaScript?

- JavaScript (JS) is a high-level, interpreted programming language.
- It is dynamic, multi-paradigm (supports procedural, object-oriented, and functional programming).
- Primarily used to make web pages interactive (e.g., animations, form validation, dynamic content updates).
- Runs on the client side (in the browser) but can also be used on the server side (Node.js).
- Not related to Java (name similarity is due to marketing reasons).

## Features of JavaScript

| Feature               | Description                                                             |
| --------------------- | ----------------------------------------------------------------------- |
| Lightweight & Fast    | Executes directly in the browser without compilation.                   |
| Dynamically Typed     | Variables can hold any data type (no explicit type declaration).        |
| Event-Driven          | Responds to user actions (clicks, keypresses, etc.).                    |
| Asynchronous          | Supports callbacks, promises, async/await for non-blocking operations.  |
| Cross-Platform        | Works on browsers, servers (Node.js), and mobile (React Native, Ionic). |
| Prototype-Based OOP   | Uses prototypes instead of classical inheritance.                       |
| First-Class Functions | Functions can be assigned to variables, passed as arguments.            |

## Use Cases of JavaScript

| Area                     | Usage                                                                    |
| ------------------------ | ------------------------------------------------------------------------ |
| Web Development          | DOM manipulation, form validation, animations (React, Angular, Vue).     |
| Server-Side              | (Backend) Using Node.js to build APIs, real-time apps (e.g., chat apps). |
| Mobile Apps              | Frameworks like React Native, Ionic for cross-platform apps.             |
| Desktop Apps             | Electron.js (e.g., VS Code, Slack).                                      |
| Game Development         | Browser games using HTML5 Canvas or libraries like Phaser.               |
| IoT (Internet of Things) | JavaScript (Node.js) used to control smart devices.                      |
